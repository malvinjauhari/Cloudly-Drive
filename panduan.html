Cloudly Drive

Panduan Setup & Deployment

Sebelum Memulai

Pastikan kamu sudah menyiapkan:

  • Akses ke Google Apps Script (script.google.com)
  • Minimal 2 akun Google: 1 Master + 1 Worker
  • File Cloudly Drive Config.xlsx dari folder assets/
1

Siapkan Akun Master & Worker

Siapkan akun Google yang akan digunakan sebagai Master (pengelola) dan Worker (penyimpanan file).

Master: Akun utama yang mengelola semua file dan user. Bisa akun Google biasa.

Worker: Akun Google Drive yang akan menyimpan file. Gunakan Shared Drive agar kuota tidak cepat penuh.

Tips:

  • Bisa pakai banyak Worker sekaligus (multi-drive)
  • Pastikan Worker sudah -share aksesnya ke Master
2

Buat Folder di Masing-masing Akun

Buat folder khusus agar file terorganisir dan tidak berantakan.

Di Akun Worker:

  1. Buka Google Drive
  2. Buat folder baru, misal: Cloudly Storage
  3. Copy Folder ID dari URL (bagian setelah /folders/)
  4. Share folder tersebut ke akun Master (Editor)

Di Akun Master:

  1. Buka Google Drive
  2. Buat folder baru untuk backup opsional
  3. Pastikan bisa mengakses folder Worker yang sudah di-share
Penting: Folder ID Worker akan dimasukkan ke spreadsheet nanti. Contoh ID dari URL:
https://drive.google.com/drive/folders/1ABC123def456...
3

Buat Spreadsheet Konfigurasi

Buat spreadsheet baru dari template yang sudah disediakan.

  1. Buka file assets/Cloudly Drive Config.xlsx
  2. Klik File → Buat Salinan (Make a Copy) ke akun Google kamu
  3. Buat menjadi Google Spreadsheet
  4. Edit sheet berikut:

4

Deploy Worker App (DULU)

STEP INI DULU

Worker harus di-deploy terlebih dahulu karena URL-nya dibutuhkan di spreadsheet.

  1. Buka akun Google Worker (akun yang tadi dibuat)
    Kemudian buka script.google.com
  2. Buat Project Baru: Klik "Proyek baru" (New Project)
  3. Paste kode worker:
    Buka file worker/worker-code.gs dari repository ini
    Copy seluruh isi file, paste ke Code.gs di Apps Script (replace semua isi default)
  4. Tambahkan Drive API:
    Klik Services (+) di panel kiri → pilih Drive API → klik Tambahkan (Add)
    Ini wajib agar worker bisa membaca kuota drive
  5. Set Folder Target (opsional):
    Jika ingin file masuk ke folder tertentu (bukan root drive), buat file setup.gs sementara: 
    function setup() {
  PropertiesService.getScriptProperties().setProperties({
    'SECRET_KEY': 'RAHASIA_MASTER_SAMA',
    'TARGET_FOLDER_ID': 'ID_FOLDER_YANG_TADI'
  });
}

    Jalankan fungsi setup() sekali, lalu hapus file setup.gs

    Jika tidak diisi, file akan masuk ke Root Drive Worker

  6. Deploy:
    Klik Deploy → Deployment baru → Web App
    Isi: Description = Worker v1, Execute as = Me, Who has access = Anyone
    Klik Deploy → Salin Web App URL
  7. Simpan URL ke Spreadsheet:
    Kembali ke Google Spreadsheet → Sheet DRIVES
    Tempel Web App URL ke kolom Web App URL pada baris Worker yang sesuai
5

Deploy Master App

Sekarang setup Master yang akan menjadi dashboard utama.

  1. Buka akun Google Master (akun utama)
    Kemudian buka script.google.com
  2. Buat Project Baru: Klik "Proyek baru" (New Project)
    Ganti nama project menjadi Cloudly Drive
  3. Set Credentials dulu:
    Buat file baru bernama setup.gs, paste kode ini: 
    function setupMasterCredentials() {
  PropertiesService.getScriptProperties().setProperties({
    'SPREADSHEET_ID': 'ID_SPREADSHEET_KAMU',
    'SECRET_KEY': 'RAHASIA_YANG_SAMA_DENGAN_WORKER'
  });
}

    Ganti nilai placeholder, lalu jalankan fungsi setupMasterCredentials()

  4. Paste semua file Master:
    Buka folder master/ dari repository ini
    Untuk setiap file *.gs dan *.html, buat file baru di Apps Script dengan nama yang sama:
    app.gs
    auth.gs
    dashboard.gs
    files.gs
    settings.gs
    users.gs
    workers.gs
    activity.gs
    utils.gs
    css.html
    index.html
    js-api.html
    js-app.html
    js-bulk.html
    js-modals.html
    js-ui.html
    js-upload.html
    js-utils.html

    * setup.gs boleh dihapus setelah setup selesai

  5. Deploy:
    Klik Deploy → Deployment baru → Web App
    Isi: Description = Cloudly Drive v1, Execute as = Me, Who has access = Anyone
    Klik Deploy → Salin Web App URL
6

Buka Dashboard & Login

Buka Web App URL Master di browser, lalu login dengan akun yang sudah dibuat di spreadsheet.

  1. Buka Web App URL Master di browser
  2. Masukkan Username dan Password dari sheet USERS
  3. Pilih akun Worker / "Semua Akun"
  4. Dashboard siap digunakan!

Selesai!

Cloudly Drive sudah siap digunakan. Upload, kelola, dan download file dari satu dashboard.

Troubleshooting

Worker tidak muncul / error connection:

  • Pastikan Worker sudah di-deploy dengan akses Anyone
  • Pastikan URL Worker benar di spreadsheet (sheet DRIVES)
  • Pastikan Drive API sudah diaktifkan di Worker

Upload gagal:

  • Pastikan SECRET_KEY di Master dan Worker sama
  • Pastikan folder sharing sudah di-share ke akun Master

Login gagal:

  • Pastikan SPREADSHEET_ID benar di Master
  • Pastikan data user sudah benar di sheet USERS
